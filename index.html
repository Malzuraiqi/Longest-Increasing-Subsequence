LIS Algorithm

Longest Increasing Subsequence | Mohammed Hesham

What is LIS?

The Problem

Given an array, find the longest subsequence where every element is strictly greater than the previous. Elements do not need to be adjacent, only in order.

In [3,1,4,1,5,9,2,6], one LIS is [1,4,5,9] with length 4.

Two Algorithms

DP O(n^2) - Build a table where dp[i] = length of LIS ending at index i. For each i, scan all j < i.

Patience Sort O(n log n) - Place cards on sorted piles using binary search. Number of piles = LIS length.

Key Insight

Patience sort maintains pile tops in sorted order. This invariant enables binary search, reducing the O(n) inner scan to O(log n) and turning O(n^2) into O(n log n).

Subsequence vs Substring: A subsequence preserves order but skips elements. [1,4,9] is a subsequence of [3,1,4,1,5,9]. A substring must be contiguous.
Optimal Substructure: The best LIS ending at i depends only on the best LIS ending at each j < i where A[j] < A[i]. Build big from stored small.

CLO Analysis - Complexity, Searching & Design Paradigm
CLO-1: Complexity
Algorithm Time Space
DP O(n^2) O(n)
Patience O(n log n) O(n)
Binary search replaces the O(n) inner scan. Since pile tops are always sorted, each element is placed in O(log n). Total: n log n.
- O(n^2) DP - O(n log n) Patience
CLO-2: Binary Search Role
Sorted invariant: Pile tops are always strictly increasing. So binary search applies: find the leftmost pile whose top >= A[i] in O(log n).
Step DP scan Binary search
Find pile O(n) O(log n)
Per element O(n) O(log n)
Total O(n^2) O(n log n)
In the Patience tab, the purple dashed box is the active search range. It narrows each step - that narrowing is O(log n) in action.
CLO-3: Dynamic Programming
Recurrence:
dp[i] = 1 (base)
dp[i] = max(dp[j]+1) for all j<i where A[j]<A[i]
Answer = max(dp[0..n-1])
Optimal Substructure: The best LIS ending at i uses the best LIS ending at some earlier j. We only need the optimal, not all possibilities.
Overlapping Subproblems: dp[j] is reused by every future dp[i] where A[j] < A[i]. Storing dp[] avoids recomputation - turning exponential recursion into O(n^2).
